# Credits

This handbook is written from three sources. None of its text is copied from them.

## PCGen itself

[PCGen](https://pcgen.org) is free software built by volunteers. Everything factual
here was read from its source code.

- Source: [github.com/PCGen/pcgen](https://github.com/PCGen/pcgen)
- Pinned commit for this build: [`d4ade6d5`](https://github.com/PCGen/pcgen/tree/d4ade6d509f4206b1c1789848752e633ec3c134c)
- Version: `6.09.08.RC1`

PCGen's program code is under LGPL-2.1. The game data shipped with it is under the
Open Game License 1.0a.

## PCGen's official documentation

The [PCGen Documentation Project](https://pcgen.github.io/pcgen/) wrote the original
tag reference, and many of the people who built it are no longer active. This handbook
covers similar ground and reaches different conclusions in places, because it reads the
code rather than the docs. That is a comment on how long the docs have gone unmaintained,
not on the people who wrote them.

## The homebrew video lessons

A [25-video playlist](https://www.youtube.com/playlist?list=PLLa5A1qjBOPekqEC_R9BAZW-8q5IT-klM)
covering PCGen homebrew, recorded around PCGen 6.05 and 6.06. It is the only place the
actual *workflow* is shown: which file to open, in what order, and what goes wrong.

The videos shaped which tasks this handbook covers and how the how-to pages are
ordered. They were used as research; no transcript text is reproduced here, and the
transcripts are not published. Where a video shows something that has since changed,
this handbook gives the current behaviour.

Individual pages link to the video that covers the same ground, so you can watch
someone do it.

## Examples

Example content in this handbook is invented — `Test Blade`, `Sample Feat` and so on.
Nothing is taken from the SRD or any published game book. That keeps Open Game License
attribution obligations off this site.
